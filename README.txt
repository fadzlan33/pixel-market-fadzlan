PIXEL MARKET — STARTER

1) Buka index.html di browser untuk mode demo. Data hanya tersimpan di browser itu.
2) Untuk data online, buat project di https://supabase.com/
3) Buka SQL Editor, jalankan isi schema.sql.
4) Dari pengaturan API project, salin Project URL dan anon/public key.
5) Edit index.html, isi SUPABASE_URL dan SUPABASE_ANON_KEY. Jangan pernah gunakan service_role key.
6) Unggah index.html ke GitHub sebagai index.html dan aktifkan GitHub Pages.
7) Tes dari browser lain. Iklan yang diajukan online berstatus pending dan baru terlihat setelah disetujui admin.
8) Pembayaran belum tersedia. Jangan terima uang sungguhan sebelum sistem admin, keamanan, pemeriksaan area di server, dan pembayaran diuji.
Catatan: simpan logo dalam data URL hanya cocok untuk prototipe kecil dan bisa cepat memenuhi kuota database.
